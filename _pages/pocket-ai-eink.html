A pocket voice assistant without the distractions of a phone. Ask a question, delegate a task, and check its status on a quiet e-paper display.

What it does

The ESP32-S3 handles microphone and speaker audio, an e-paper status display, battery indication, light sleep, and backup Wi-Fi. Gemini Live provides voice conversations. A separate AI agent backend handles delegated tasks and sends completion notifications back to the device.

The firmware includes acoustic echo cancellation and an interchangeable backend interface, so you can connect an agent through a compatible API or adapter.

Where local AI fits

Your Hermes agent can run on your own computer or server and use local AI models. The ESP32 is the voice interface; it does not run the language model. This version uses cloud-based Gemini Live for voice conversations, so the complete setup is not fully offline.
